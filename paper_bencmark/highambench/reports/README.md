# HighamBench measurement reports

The current report is the [combined r09+r10 report](combined-r09-r10/README.md). It uses r10 for the 30 successfully rerun pairs and r09 for the other 87 pairs.

The [r09-only report](live-r09/README.md) is retained as historical evidence and should not be used as the current aggregate report.

Both reports show N and L directly. LOC is counted only from the submitted accepted Lean file: imports count as submitted lines, but the internal contents of imported Mathlib and NumStability modules or declarations do not.

The P12-T1 and P17-T1 rows in both reports are historical measurements of superseded targets. The current equation-(8) P12-T1 and equation-(4.12) P17-T1 tasks are not yet measured.
