### Floating point foundations

[Model.lean](/library/NumStability/FloatingPoint/Model.lean:11) owns `NumStability.BasicOp` (`add`, `sub`, `mul`, `div`), `BasicOp.exact : BasicOp → ℝ → ℝ → ℝ`, and `FPModel`. An `FPModel` stores `u : ℝ` with `0 ≤ u`, deterministic functions `fl_add`, `fl_sub`, `fl_mul`, `fl_div : ℝ → ℝ → ℝ`, and `fl_sqrt : ℝ → ℝ`. Its `model_add`, `model_sub`, and `model_mul` fields give an existential `δ` with `|δ| ≤ u` and `fl(x op y) = (x op y) * (1 + δ)`. `model_div` also requires `y ≠ 0`; `model_sqrt` requires `0 ≤ x`. The extra law `fl_add_zero` says `fl_add 0 x = x`. `FPModel.round : BasicOp → ℝ → ℝ → ℝ` selects the four binary operations, and `FPModel.model_basicOp` combines their laws with the division side condition. These types and fields were confirmed by `#check`.

[Rounding.lean](/library/NumStability/Analysis/Rounding.lean:42) owns `gamma (fp : FPModel) (n : ℕ) : ℝ`, defined as `n * fp.u / (1 - n * fp.u)`, and `gammaValid (fp : FPModel) (n : ℕ) : Prop`, defined as `n * fp.u < 1`. Its checked `prod_error_bound` converts `Fin n` factors bounded by `fp.u` into `∏ i, (1 + δ i) = 1 + θ` with `|θ| ≤ gamma fp n`. `prod_signed_error_bound` handles factors or their reciprocals. The checked `gamma_mul`, `gamma_inv`, and `gamma_div` combine bounded factors; inverse and division rules need a positive denominator factor and stronger `gammaValid` counts. [RoundingProductBounds.lean](/library/NumStability/Analysis/RoundingProductBounds.lean:196) also provides a direct product radius and sharper small-`n*u` bounds.

### Representation and search limits

`FPModel` fixes one output for each operation and operand pair. Its existential error witnesses can vary by call, but the stored operation cannot independently return different answers for identical inputs. It supplies neither stochastic rounding nor finite exponent and precision semantics. [FloatingPointArithmetic.lean](/library/NumStability/Analysis/FloatingPointArithmetic.lean:5966) separately defines `FloatingPointFormat` (`beta`, `t`, `emin`, `emax`), `unitRoundoff`, `finiteRoundToEven`, and `finiteRoundToEvenOp`. [Error.lean](/library/NumStability/Analysis/Error.lean:249) separately defines `NoGuardFPModel` with weaker addition and subtraction laws.

Conventions matter when comparing an external algorithm: `fl_recursiveSum` starts at zero, with the first addition exact by `fl_add_zero`; `fl_dotProduct` starts from the first rounded product, avoiding an extra addition; `fl_hornerDesc` takes coefficients in descending order. `fl_kahanSum` returns the state’s sum component, while [Kahan/Exactness.lean](/library/NumStability/Algorithms/Summation/Compensated/Kahan/Exactness.lean:156) also defines a final-corrected output.
