# Supplemental compiled probe outputs

The original audit report links to this directory as the location of generated
`.olean` and `.ilean` probe outputs. These 60 compiler products were not listed
in `ARTIFACT_SHA256SUMS`, but are retained as supplemental link-preservation
artifacts because they are small and preserve the complete probe record.

The manifest-covered source files, result tables, logs, hashes, and validation
records needed to audit the reported 15/15 outcomes are retained in the parent
`probes/` directory. The outputs here are derived artifacts and are covered by
`../../SUPPLEMENTAL_SHA256SUMS`, not by the authoritative 485-file manifest.
